CareerLens Agent — Agentic RAG 求职文档分析助手
- 项目背景：面向大模型算法岗求职场景，构建一个能自动规划任务、混合检索资料、反思验证结论的 Agentic RAG
  系统，解决传统单轮问答缺乏求职上下文关联和证据溯源的问题。
 - 项目描述：
    - 设计并实现了一个具备 Planner → Tool Routing → Reflection → LongTermMemory 四阶段闭环的 Agent
       引擎，支持岗位匹配和简历诊断两种工作模式的自动路由
    - 搭建 Chroma 稠密向量 + BM25 稀疏关键词 + RRF 倒数秩融合的混合检索管线，检索结果相关性 ≥97%
    - 基于 LangChain 封装 RAG 链，结合 DashScope Qwen 实现 SSE 流式生成，首字响应 <1s
    - 完成 FastAPI 后端（9 个 API 端点）和原生前端 SPA（登录/上传/多会话聊天），整体代码 ~1500 行
    - 从零基于开源项目参考架构独立实现，将 Milvus 依赖替换为 Chroma 降低部署门槛，免 Docker 本地一键启动
